## Présentation

Même outil que Frontekas, adapté au plan de numérotation camerounais.

**Pourquoi ce choix.** Chaque pays a son format ; l'outil est décliné plutôt que paramétré, pour rester immédiat.

## Ce que fait le projet

- Génération par plage
- Format camerounais
